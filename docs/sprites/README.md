# Спрайты: эскизы для v2.1.0

Здесь лежат материалы для перехода с простых фигур на SVG-спрайты (v2.1.0) — чтобы потом сравнить, как было и как стало.

| Файл | Что это |
|---|---|
| `sprites-draft.html` | эскизы спрайтов шахтёра и тварей с анимацией — открыть в браузере |
| `sprites-preview.png` | снимок эскизов: сравнение «сейчас / 20 / 28 / 36 px» и все кадры |
| `2.0.0/` | как игра выглядит в версии 2.0.0 — простые фигуры: общий вид, твари, копание, подъём |

Решено:

- шахтёр — кепка с фонарём, усы, рубаха с подтяжками, кирка; позы: стоит, идёт (4 кадра), копает (2), лезет (2);
- твари: крыса (бежит), летучая мышь (летит, спит на потолке), паук (ползёт), саламандра (ползёт, прячется в лаве);
- **масштаб по умолчанию — 28 px** («средне»); в настройках — «мелко» (20 px, как в 2.0.0) и «крупно» (36 px).
